# Python ATM Simulator

A simple ATM simulation project written in Python.

## Features

* Check account balance
* Deposit money
* Withdraw money
* Password authentication
* Menu-based interface
* Exit option

## Requirements

* Python 3.13.7x
## Example

```
How much balance do you want?: 1000
Your password: 1234

1 = Check Balance
2 = Add Balance
3 = Withdraw Money
4 = Exit
```

## Technologies Used

* Python
